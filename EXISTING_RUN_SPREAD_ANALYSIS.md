# Follow-up analysis of the completed full run

**Purpose.** The overall experiment has many outbreaks with little opportunity for downstream spread. In a diagnostic replay of the untreated scenarios, about 84% infected only the starting node. This analysis asks whether CIB helps more when the *same outbreak would have spread without immunization*. It uses the completed `output/1/` run; it does not rerun the immunization strategies.

## Rough procedure

1. Read `output/1/manifest.json`, `output/1/raw.csv`, and the saved `activities-*.csv` files. For each unique `(network, activity, beta, trial)`, load the network and activity snapshot, then replay one **untreated** cascade. Initialize the RNG from that trial's `evaluation_seed`; call `sample_seeds` before `model.scenario(rng)`, matching the runner's order. Finish the cascade with no immunized nodes. Each untreated scenario is shared across the four budget fractions, so reconstruct it once.
2. Record untreated infection count and depth. Useful strata are **no spread** (only the initial seed), **one transmission wave**, and **two or more transmission waves**. In the current `CascadeModel`, these correspond to `steps == 1`, `steps == 2`, and `steps >= 3`. Also report size thresholds such as at least five untreated infections; reaching one neighbor alone provides little downstream path for CIB to anticipate.
3. Join those untreated labels to `raw.csv` by `(network, activity, beta, trial)`. Within each network, activity distribution, beta, and budget, compare methods on the **same trial**. Prioritize dynamic pure CIB (`hybrid`, `alpha=0`) versus adapted MIG, dynamic AR+CIB versus MIG and AR, and static pure CIB versus static AR. Report paired differences in final infected count, actual immunizations used, and the number of trials in each stratum.
4. Show the full-run results alongside every untreated-spread stratum. For static methods, account for the five reused plans when estimating uncertainty; 20 outbreaks from one plan are not 20 independent planning replicates. Treat small subgroups cautiously and report intervals rather than only which mean is lower.

**Interpretation.** The strata depend on the untreated outbreak, not on a method's outcome, so methods remain paired on the same underlying scenario. This subgroup question was chosen after seeing the primary results: label it **exploratory**, keep all strata visible, and do not replace the full-sweep conclusion with only the favorable subgroup. This analysis can indicate whether a separate, more spreading experiment is worth running.
